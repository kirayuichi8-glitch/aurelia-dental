# Aurelia Dental

Премиальный демонстрационный сайт стоматологии для портфолио: адаптивный лендинг, мягкие анимации, сценарный помощник без платного AI API и реальная отправка заявок в D1.

## Возможности

- Адаптивная главная страница с продающей структурой.
- Интерактивный помощник «Аура» с базой частых вопросов.
- Форма записи с проверкой данных и хранением заявок.
- Доступность: клавиатура, подписи, режим без анимаций.
- Cloudflare Worker-совместимая сборка без внешних runtime-зависимостей.

## Запуск

```bash
npm run dev
```
