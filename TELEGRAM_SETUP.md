# Подключение Telegram к Aurelia

Система уже умеет сохранять заявки и приёмы, уведомлять администратора, связывать пациента с записью и напоминать за два часа. Для запуска нужны бесплатный бот и пять переменных окружения.

1. В Telegram откройте `@BotFather`, выполните `/newbot` и сохраните выданный токен.
2. Укажите имя бота без `@` в `TELEGRAM_BOT_USERNAME`.
3. Напишите созданному боту любое сообщение и определите числовой идентификатор административного чата; укажите его в `TELEGRAM_ADMIN_CHAT_ID`.
4. Создайте две длинные случайные строки для `TELEGRAM_WEBHOOK_SECRET` и `REMINDER_SECRET`.
5. Добавьте значения в переменные окружения опубликованного сайта. Не храните реальные секреты в GitHub.
6. Один раз выполните `POST /api/telegram/setup` с заголовком `Authorization: Bearer <REMINDER_SECRET>`.
7. Для надёжных напоминаний настройте бесплатный вызов `POST /api/reminders/run` раз в 5–10 минут с тем же заголовком. Также поддерживается стандартный Cloudflare Scheduled Worker.

Telegram не разрешает боту писать человеку по номеру телефона. Поэтому после отправки формы пациент нажимает кнопку подключения напоминаний и запускает бота сам.
